## Context（背景）

变更动机见 `proposal.md`，行为要求见 `specs/mmc-multimaterial-simultaneous-optimization/spec.md`。

当前 3D MMC 主循环位于 `Cuda_TopOpt_Pipeline.cu`。它内部持有 MMC 组件结构、九变量 TDF 导数、KS 组件并集、正则化 Heaviside、单元占有率、几何体积梯度和持久化 MMA 状态。当前顺序流程先把该 MMC 求解器完整运行至结束，再把最终占有率按阈值转换成固定活动单元集合，最后调用 `Cuda_TopOpt_MultiMaterial_SIMP.cu` 中独立的双材料阶段。

同步模式不能直接组合这两个公开函数，因为它们各自拥有完整的优化循环，无法共享同一个当前位移场和联合设计状态。因此需要新增独立循环，在同一当前状态下计算两组变量。现有算法实现属于兼容性边界，必须保留其代码路径和行为。

## Goals / Non-Goals（目标 / 非目标）

**目标：**

- 仅通过新增函数和独立源文件实现隔离的 MMC 几何与双材料联合优化求解路径。
- 在现有 MMC 优化界面中增加独立入口，并保持原 MMC 入口、参数和事件处理不变。
- 复用现有 3D MMC 占有率及其导数的已验证数学逻辑，同时不改变现有求解器行为。
- 每轮使用同一个位移解和同一个单元能量场计算两组解析梯度。
- 使新的耦合导数在单元层面明确且可验证。
- MMC 组件移动过程中保持材料设计向量的拓扑不变。

**非目标：**

- 修改、重写、重构或替换独立 MMC、独立 SIMP 或顺序 MMC+SIMP 求解函数的函数体、控制流程、参数语义或原入口映射。
- 实现 Guo 等人论文中的壳-填充构造、内缩组件或 min/max 最终密度表达式。
- 在初始版本中增加材料密度滤波、材料 Heaviside 投影或制造约束。
- 支持不同泊松比或一般各向异性本构插值。
- 把第一版实现为双层优化，即每次 MMC 更新都将材料子问题完全求解至收敛。

## Decisions（设计决策）

### 1. 新增独立求解器模块与状态

新增 `Apps/SolverGPU/Cuda_TopOpt_MMC_MultiMaterial_Simultaneous.h`、`Apps/SolverGPU/Cuda_TopOpt_MMC_MultiMaterial_Simultaneous.cu` 以及同名公开函数，不修改任何现有优化循环。新模块独立持有 MMC 组件、完整网格材料向量、变量上下界、优化器历史、诊断和输出。

`Cuda_TopOpt_Pipeline.h/.cu`、`Cuda_TopOpt_MMC_SIMP_Sequential.h/.cu` 和 `Cuda_TopOpt_MultiMaterial_SIMP.h/.cu` 是只读算法兼容性边界。本变更不得修改这些文件中的算法函数、循环、条件分支、默认参数或调用关系。

新模块需要的 MMC 组件计算将以局部纯函数形式实现，遵循现有方程和九变量顺序。若共享帮助函数必须改动旧算法文件，则不进行抽取，而是在新模块中局部实现所需逻辑。为严格遵守兼容性边界，本次接受少量逻辑复制；未来若要抽取公共帮助函数，应单独进行行为不变的重构，不属于本变更范围。

备选方案：交替调用 `Cuda_TopOpt_MMC_Node` 与 `RunMultiMaterialSIMPStage`。不采用，因为两个函数都会完整运行各自循环，无法共享一次当前位移求解或固定的联合设计状态。

### 2. 使用一个单元系数作为耦合点

对单元 `e` 定义：

```
m_e   = 当前 MMC 单元占有率
eta_e = 当前双材料设计变量
E_e   = eta_e^p E1 + (1 - eta_e^p) E2
a_e   = m_e E_e
K_e   = a_e K_e^0
```

`K_e^0` 在单位杨氏模量和配置的共同泊松比下计算。传给密度缩放有限元装配的是 `a_e`，而不是 `eta_e`。新流程使用调用方传入的 `E1` 和 `E2`，不复现顺序流程在局部覆盖这两个数值的行为。

备选方案：复用论文的 `min(max(...))` 壳-填充密度。不采用，因为本能力只有一个 MMC 占有率场，没有内层组件场，也没有生成空域的 SIMP 场。

### 3. 复用直至单元占有率的既有 MMC 导数

既有 MMC 链条在概念上保持不变：

```
d_ir -> 组件 TDF -> KS 并集 -> Heaviside -> m_e
```

将其结果记为：

```
G_mmc[e, ir] = dm_e / dd_ir
```

同步模式只增加耦合导数：

```
da_e / dm_e = E_e
```

令 `q_e = U_e^T K_e^0 U_e`，则 MMC 目标梯度为：

```
dC/dd_ir = -sum_e(E_e q_e G_mmc[e, ir])
```

`E_e` 必须在单元贡献完成累加之前应用。在现有节点能量累加模式下，新流程的单元贡献由 `q_e / 8` 变为 `E_e q_e / 8`；其后的 KS、Heaviside 和 TDF 导数沿用既有 MMC 逻辑。

MMC 几何体积值与导数继续使用既有占有率定义及导数路径。

备选方案：用一个模量去乘已完成汇总的独立 MMC 梯度。不采用，因为同步材料变量通常使各单元具有不同的 `E_e`。

### 4. 初始版本直接使用双材料插值导数

初始同步模式直接将每个原始 `eta_e` 作为插值输入：

```
dE_e/deta_e = p eta_e^(p-1) (E1 - E2)
dC/deta_e   = -m_e q_e dE_e/deta_e
```

第一版不增加材料密度滤波或投影，使解析导数保持局部形式，便于直接复用并逐项核对现有材料插值逻辑。后续可在独立变更中加入滤波和投影，并明确相应链式因子与验收条件。

备选方案：复用当前事后灵敏度过滤。不在第一版采用，因为它不是某个经过滤波的设计场的严格导数，会干扰最初的联合梯度验证。

### 5. 材料变量固定在完整网格上

初始化时为所有单元分配 `eta`，并在整个运行过程中保持该映射。MMC 占有率同时缩放材料的目标影响和材料资源统计，不再构造 `mmc_density > threshold` 的活动单元集合。

这意味着近似空域中的材料值暂时处于潜伏状态，直到 MMC 占有率移动到相应位置。统一初值和有界 MMA 移动限制可减小新占有单元出现时的瞬态。

备选方案：每次 MMC 更新后重建材料活动变量。不采用，因为变量维数变化会使优化器历史失效，并引入不可微的拓扑事件。

### 6. 使用一个持久化联合 MMA 优化器

根据各自上下界归一化 MMC 控制变量，再与已处于单位尺度区间的 `eta` 拼接。为联合向量创建一个持久化 MMA 求解器，使两组变量基于同一目标与约束线性化同时更新。

约束集合包括：

1. 既有 MMC 几何体积不等式；
2. 使用两个带容差不等式表示的占有率加权材料比例等式。

当 `f = V2 / V1` 时：

```
V1 = sum_e(m_e eta_e v_e)
V2 = sum_e(m_e (1 - eta_e) v_e)
R  = V2 - f V1
R - tolerance <= 0
-R - tolerance <= 0
```

需要计算资源约束对两组变量的梯度，因为即使 `eta` 固定，MMC 占有率移动也会改变 `V1` 和 `V2`。

备选方案：在同一个外层循环中对 MMC 使用持久化 MMA、对材料使用 OC。不在第一版采用，因为当前软材料变量具有正的柔顺度导数，现有 OC 符号约定还需要单独验证；联合 MMA 可以直接使用真实梯度。

### 7. 每轮只定义一个被接受状态

每次迭代按以下顺序执行：

1. 计算 MMC TDF、组件并集、Heaviside、占有率及占有率导数；
2. 计算所有单元的 `E_e` 和 `a_e`；
3. 装配并求解一次平衡方程；
4. 计算 `q_e`、目标、两组目标梯度、约束和所有约束梯度；
5. 对拼接后的设计变量只更新一次；
6. 解包已接受的 MMC 与材料状态并判断收敛。

灵敏度诊断只读取当前已接受状态及其解析梯度数组，不得替换设计变量或推进优化器历史。

### 8. 保持输出字段语义独立

新结果导出至少包含：

- `mmc_occupancy`：`m_e`；
- `material_eta`：`eta_e`；
- `material_modulus`：`E_e`；
- `effective_stiffness`：`a_e`。

这样可以避免使用一个 `density` 字段同时表达几何、材料选择和刚度三种含义。

### 9. 在现有 MMC 优化界面增加独立入口

在当前用于启动 3D MMC 优化的同一界面或面板中增加“MMC-多材料同步优化”选项及其双材料参数输入。原标准 MMC 控件、默认值和触发路径保持不变。

分发映射固定为：

- 标准 MMC 选项继续调用原 MMC 入口；
- MMC-多材料同步优化选项只调用 `Cuda_TopOpt_MMC_MultiMaterial_Simultaneous(...)`；
- 顺序 MMC+SIMP 选项继续调用原顺序优化入口。

对 `Apps/Poster/source/iGamePoster.cpp`、`Apps/Poster/source/Topopt_GPU_Version.cpp` 及构建注册文件只允许进行新控件、新参数传递、新头文件包含和独立分发分支所需的最小接线；不得改变任何已有分支的条件、调用目标和参数语义。

## Risks / Trade-offs（风险 / 权衡）

- [共享 MMC 界面时新选项可能误入原 MMC 或顺序优化分支] -> 为每个界面选项记录实际求解入口，并回归验证原选项仍调用原函数，只有新选项调用新增函数。
- [复制的 MMC 帮助逻辑可能与独立求解器逐渐偏离] -> 记录其来源公式，为占有率与 `dm_e/dd_ir` 增加一致性测试，不隐式修改任意一份实现。
- [联合 MMA 设计向量可能很大] -> 复用求解器的向量式多约束路径，归一化 MMC 变量，并在启用大规模算例前测量代表性网格的内存与耗时。
- [替代材料占有率使外部材料变量具有很小但非零的影响] -> 第一版为保持一致性继续使用现有占有率约定，在诊断中报告外部贡献，并把物理占有率归一化留给后续独立提案。
- [第一版没有材料滤波，可能产生棋盘格或网格依赖] -> 先通过解析公式逐项核对、均匀材料退化一致性和端到端收敛表现确认原始梯度正确接入；滤波和投影留给后续独立变更。
- [严格的材料比例等式可能使早期 MMA 子问题难以求解] -> 使用可配置的等式容差、保守移动限制，并分别报告两个有符号残差。
- [MMC 与材料梯度尺度不同] -> 归一化几何变量，并监控两组梯度范数和步长。
- [节点累加可能在单元信息丢失后才错误应用 `E_e`] -> 在每次单元到节点贡献时应用 `E_e q_e`，记录非均匀材料场中的逐单元贡献，并进行均匀材料退化一致性检查。

## Migration Plan（迁移计划）

1. 新增并测试求解器模块，暂不接入现有分发路径。
2. 在相同组件状态下，对照独立 MMC 验证占有率和几何体积导数的一致性。
3. 在固定 MMC 占有率下，用端点值、中间值和闭式导数逐项核对材料插值及局部材料梯度。
4. 使用非均匀 `E_e` 场确认 MMC 梯度在单元累加时采用各自模量，并用均匀材料场验证其退化为既有 MMC 梯度的模量缩放形式。
5. 在现有 MMC 优化界面中增加新选项，并通过独立分发分支连接到新增函数；对照分发日志确认原 MMC 与顺序 MMC+SIMP 选项仍映射到原入口。
6. 回滚时只需移除或禁用新分发选项和新模块；现有求解路径不需要迁移。
